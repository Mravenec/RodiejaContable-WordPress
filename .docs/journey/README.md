# Journey docs

One markdown file per epic: `{n}-{slug}.md`.

This is a **product** repo — journeys are the living epic story (why / acceptance / agent notes / verify), same role as in the Spring harness. Update them as tickets move; do not leave “Planned” stubs after work lands.

Board snapshots: `.docs/board/{n}-{slug}/`. Process: `.ai/rules/board-process-mandatory.md`.
