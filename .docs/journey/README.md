# Journey docs

One markdown file per epic: `{n}-{slug}.md`.

This is a **product** repo — journeys are the **living** epic story (Why / What we did / Acceptance / Agent notes / Verify / Outcome). Same pillar as `.linear` tickets and `.docs/board` snapshots.

**Always:** keep the journey truthful as tickets move. After summarize/land → **Status: Done**, Outcome filled, no “Planned” / “Describe the problem…” placeholders. Every board epic must have a matching journey file.

Board snapshots: `.docs/board/{n}-{slug}/`. Rules: `.ai/rules/journey-epic.md` · `.ai/rules/board-process-mandatory.md`.
